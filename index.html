What happens in those few seconds

It reads, it checks, then it explains

Reading runs on the phone; an optional Cloud check adds a second, AI reading beside it. A value it cannot read for certain stays blank for you to fill. It never puts a plausible number where it was unsure.

Reads the screen

Each row is matched label to value, even with the phone tilted and the screen striped by moiré. A lost decimal point, a minus the camera thinned out, an O printed for a 0: each is recognised against what that parameter can be.

BEb   "8.9" + pixels → −8.9
Sodium "l40.O" → 140.0
pH    "7320" → 7.320

Checks it against the screen

Most analysers also print tCO₂ and an anion gap. Those only add up if pCO₂, HCO₃⁻ and the electrolytes landed on the right rows, so the reading is verified before you see it.

tCO₂ = HCO₃⁻ + 0.0301 × pCO₂
17.0 = 16.0 + 0.0301 × 32 ✓
gap 35 = 140 + 3.1 − 92 − 16 ✓

Explains with the working shown

Primary disorder, expected compensation, albumin-corrected gap, delta ratio, Stewart strong-ion gap. Every step opens to the arithmetic, so it can be checked by hand at the bedside.

ΔAG / ΔHCO₃⁻ = 20 / 8 = 2.5

Learn · inside the app

Read the gas yourself, then see the working

A separate teaching mode, green so it can never be mistaken for a patient. Each case gives a short story and a gas. Teaching cases never touch the patient side, and progress stays on your phone.

Other hospitals, other programs

It learns the screen in front of it

No setup. The order of rows, the way each value is printed, and the names a program gives its parameters are learned from ordinary scans. Type a value the app missed and it remembers what that row is called. A label it has never seen is named by the value beside it: 7.320 can only be pH, in any language.

Install

Join the closed trial

Each phone gets its own key, tied to an invite code. Clinicians joining from a talk or a department meeting use the event word they were given.

iPhone

  1. Install TestFlight from the App Store.
  2. Open the join link and install Acid-Base Scout.
  3. Open the app and copy its Device ID.
  4. Enter the ID with your invite code to get the key, then paste the key into the app.

A TestFlight build stops after 90 days; a fresh one arrives before then.

Android

  1. Download the APK.
  2. Allow installs from this source when Android asks, once.
  3. Open the app to see its Device ID, for example 2VR6-P5KA.
  4. Enter the ID with your invite code to get the key.

The key works only on that phone. A reinstall makes a new Device ID; the same invite code gets a new key.

Questions

Before you point it at a screen

What does it read?

The blood-gas panel: pH, pCO₂, pO₂, sO₂, base excess, bicarbonate, electrolytes, lactate, glucose and the haemoglobin fractions.

Where do the photos go?

Nowhere. Reading happens on the phone and photos are not uploaded. Keep the patient banner out of the frame.

What is Cloud check?

An optional second reading by an AI model, off until you switch it on. Only a strip of the table leaves the phone: the rows with parameter names and values, every long number blacked out. Where the two readings differ, the screen's own arithmetic decides, or the field is left for you. Privacy details.

What if it misreads?

Every value is shown beside the photo it came from, and you confirm them before analysis. A value it was unsure of is left blank, never guessed.

Who can join?

Invited clinicians. The ten most active testers keep the full version free at launch.

Feedback

Tell me what it got wrong

A misread value, a wrong interpretation, an idea. A screenshot from the app is the most useful report. Please, no patient details.

Decision support, not a diagnosis.

This is an evaluation build, not a registered medical device. Check every photo-read value against the original result. Clinical decisions remain yours.
